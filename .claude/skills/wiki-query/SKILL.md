# llm-wiki 查詢流程

根目錄 `CLAUDE.md` 的 `[W3]` 是常駐的那一句，這份是查詢當下才需要的細節。
兩者衝突時以 `CLAUDE.md` 為準。

## 順序

1. 先讀 `Wiki/index.md` 找候選頁——它的一行摘要就是為了這一步寫的（`[I6]`）。
2. 再讀候選頁內文。
3. **需要時才**回頭讀 `Raw/` 原文。原文只讀不改（`[L1]`）。

（推論）這個順序本身是 progressive disclosure 的手工版：先載入索引，再決定載入哪幾頁，
而不是把整個 `Wiki/` 拖進脈絡。見 `Wiki/concepts/context-engineering.md`。

## 引用與誠實義務

- **回答必附頁面引用。**
- wiki 裡沒有的，明說「**wiki 內查無**」，不要用模型知識填補而不聲明。
- 要用模型知識或網路搜尋補洞，**必須先聲明**再補。
- 答完問一句要不要存進 wiki。

## `[W4]` 輸出格式依問題而定

| 問題型態 | 輸出 |
|---|---|
| 比較題 | 表格 |
| 演變題 | 時間軸 |
| 要簡報 | 產 Marp |
| 要圖表 | 產 matplotlib 圖，存進 `Raw/assets/` |
